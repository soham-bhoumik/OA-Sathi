# OA-Sathi

OA-Sathi is a responsive, client-side demonstration of a community osteoarthritis screening workflow for the North Eastern Region of India.

## Run locally

```sh
npm install
npm run dev
```

## About the screening

The sample records and screening score are illustrative. The score is a transparent, deterministic demo heuristic—not a clinically validated prediction, diagnosis, or triage recommendation. A screening summary encourages follow-up with a qualified health professional.

No screening information is sent to a server or persisted. Records remain in memory in the current browser session and are cleared when the page reloads or closes.
